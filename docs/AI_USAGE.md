# Uso de IA — Currency Exchange App

## 1. Ferramenta utilizada

Assistente de IA (OpenCode) utilizado como apoio ao desenvolvimento incremental do
projeto, seguindo o board de desenvolvimento.

## 2. Etapas em que a IA foi utilizada

- Levantamento e estruturação dos requisitos (REQUIREMENTS.md).
- Planejamento da interface e wireframes (FIGMA.md).
- Montagem da interface inicial com JSX e CSS Modules.
- Refatoração em componentes e fluxo de props.
- Implementação de interatividade, validação e lifting state up.
- Investigação e documentação da API Frankfurter (API_TESTS.md + collection).
- Criação de funções de negócio e testes (FUNCTION_TESTS.md).
- Integração com fetch/async/await e useEffect.
- Extração de custom hook (useExchangeData).
- Implementação do gráfico (Recharts) e tabela com filtros/ordenação.
- Exportação CSV.
- Revisão de responsividade e estados.
- Preparação da documentação final (README, COMPONENTS).

## 3. Responsabilidade do desenvolvedor

A lógica de conversão, estados, efeitos, filtros, ordenação, consumo da API e
exportação foi compreendida e validada pelo desenvolvedor. As bibliotecas
utilizadas (Recharts) não substituem os conceitos trabalhados em aula.
